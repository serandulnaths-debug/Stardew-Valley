## 2024-06-05 - Semantic Widget Regions and Fallbacks
**Learning:** In the context of RemNote plugins, settings loaded via `useTracker` (e.g., `plugin.settings.getSetting`) are available synchronously, and `undefined` means the setting is simply unset by the user. Therefore, using fallback values (e.g., `name || 'User'`) instead of rendering a loading state is essential for good UX. Additionally, wrapping widgets in a semantic `<section>` element with an `aria-label` provides better accessibility compared to generic `<div>` wrappers.
**Action:** Always provide inline fallback defaults for `useTracker` settings (e.g., `?? default`) to avoid broken or empty UI strings. Use semantic HTML (e.g., `<section>`) and `aria-label`s for the root elements of custom widgets to support screen readers effectively.
