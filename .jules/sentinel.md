## 2024-05-24 - DOM-based XSS in Webpack Dev Server Sandbox Template
**Vulnerability:** In `webpack.config.js`, `HtmlWebpackPlugin` was dynamically constructing a `<script>` tag based on an unvalidated `widgetName` query parameter (e.g. `?widgetName=...`) and using `document.body.innerHTML += ...` to append an error message if missing. This introduces a DOM-based Cross-Site Scripting (XSS) vulnerability.
**Learning:** Build-time configuration templates that execute in the browser must still adhere to browser security best practices. Directly injecting URL parameters into `src` attributes or `innerHTML` without validation allows attackers to execute arbitrary code within the sandboxed environment by providing a malicious URI.
**Prevention:** Always validate URL parameters against a strict allowlist (e.g., dynamically resolving valid entry points at build time) before using them in DOM manipulation. Use safer properties like `textContent` instead of `innerHTML` to prevent script injection.
