## 2026-07-08 - Fix DOM-based XSS in HtmlWebpackPlugin template
**Vulnerability:** The `HtmlWebpackPlugin` template in `webpack.config.js` was vulnerable to DOM-based XSS. It read the `widgetName` parameter directly from the URL query string and interpolated it into a `<script src="...">` tag and used `document.body.innerHTML += ...` to display an error if the widget was missing, without validation or sanitization.
**Learning:** Build-time configuration files often generate HTML dynamically. When these templates use client-side JavaScript to read URL parameters (like `location.search`), they introduce DOM-based XSS risks if those parameters are directly written into the DOM or used to load resources.
**Prevention:** Validate URL parameters against a strict allowlist (generated at build time if possible) before using them to manipulate the DOM or load scripts. Use safe DOM APIs like `textContent` instead of `innerHTML` when displaying error messages based on user input.
