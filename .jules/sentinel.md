## 2024-07-05 - Fix DOM-based XSS in Webpack Config HTML Template
**Vulnerability:** The `HtmlWebpackPlugin` template generated an insecure `index.html` file that accepted any `widgetName` query parameter and blindly injected it into the DOM via `innerHTML` and a dynamic `<script src="...">` tag without validation. This allowed for Arbitrary Script Inclusion / DOM-based XSS if the query parameter pointed to a malicious URL or contained an XSS payload.
**Learning:** The development/sandbox environment was prioritizing ease of dynamic loading without validating the inputs. The parameter extraction was insecurely relying on user input to determine what script to execute.
**Prevention:** Construct an allowlist at build time of valid scripts/widgets using Webpack's entry point extraction. Validate the query parameter against this allowlist before generating the dynamic script tag. In addition, replace `innerHTML +=` with `textContent =` for rendering error messages to prevent basic XSS if the invalid input was displayed back to the user.
