## 2024-06-30 - Fix DOM-based XSS in HtmlWebpackPlugin template
**Vulnerability:** A critical DOM-based XSS vulnerability was identified in `webpack.config.js`. The `HtmlWebpackPlugin` template took the `widgetName` query parameter directly from the URL (`window.location.search`) and used it both to modify the DOM via `document.body.innerHTML += ...` and to dynamically include a script (`s.src = widgetName + "-sandbox.js"`). This allows attackers to execute arbitrary JavaScript by passing a malicious payload.
**Learning:** Dynamically loading scripts based on unvalidated user input (like query parameters) is highly dangerous and a classic vector for DOM-based XSS. Furthermore, `innerHTML` should never be used with user-controlled input.
**Prevention:** Always validate user-controlled input against a strict allowlist. In this case, we extracted `validWidgetNames` at build time from the Webpack entry points and validated `widgetName` against it before allowing the script to load. Additionally, when rendering error messages involving user input or generic fallback, use `document.body.textContent` instead of `innerHTML` to prevent script execution.
