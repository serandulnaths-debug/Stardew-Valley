## 2025-02-14 - Fix DOM-based XSS in HtmlWebpackPlugin template
**Vulnerability:** A DOM-based XSS vulnerability existed in `webpack.config.js` where the `widgetName` query parameter was read directly from the URL and injected into the HTML document via `document.body.innerHTML += ...` and used to construct a `<script src="..."></script>` tag without any sanitization or validation.
**Learning:** During the static generation of HTML templates, it is easy to assume that URL parameters (like `widgetName` used to dynamically load sandboxed widgets) are safe. However, dynamically executing scripts based on unvalidated input creates a critical security gap where arbitrary scripts can be executed via malicious URLs (e.g., `?widgetName=https://attacker.com/payload`).
**Prevention:** Always validate external inputs against an allowlist of expected values. Use `JSON.stringify` to safely inject static configurations into HTML templates. Furthermore, never use `.innerHTML` when setting text content; use `.textContent` instead to prevent unintended DOM parsing of malicious payloads.
