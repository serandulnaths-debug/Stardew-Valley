## 2026-07-20 - Fix DOM XSS in Sandbox Template\n**Vulnerability:** The dev server generated an `index.html` via `HtmlWebpackPlugin` that took `widgetName` directly from the URL query string (`window.location.search`) without sanitization, and appended it to a script `src` or `innerHTML`. This enabled a DOM XSS attack vector where malicious scripts could be loaded.\n**Learning:** Trusting input from `window.location.search` during local dev server initialization can lead to sandbox escapes if an attacker tricks a user into visiting a malicious URL.\n**Prevention:** Build an allowlist of valid widgets dynamically (e.g., via `glob`) and only load widgets if they match the allowlist before generating DOM elements.
