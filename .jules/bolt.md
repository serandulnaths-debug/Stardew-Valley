## 2024-03-24 - Optimizing Plugin Initialization with Promise.all
**Learning:** In RemNote plugins using `@remnote/plugin-sdk`, the `onActivate` hook initializes settings, commands, widgets, and other background tasks. A common anti-pattern is awaiting these independent asynchronous calls sequentially (e.g., multiple `await plugin.settings.register...`), which forces the plugin load to bottleneck. Since these registrations don't depend on each other's results, sequential execution unnecessarily increases activation time.
**Action:** When initializing multiple independent elements in `onActivate` (or similar startup hooks), group them into an array of Promises and execute them concurrently using `await Promise.all([])`. This pattern significantly reduces activation latency.
